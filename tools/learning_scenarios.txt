# 行は上から順に 1 つの記憶へ積み上がるので、並びを変えると結果が変わる。形式は scenarios.txt と同じ。
# 候補から選んで英語として確定した語は、以後 (見出しの読みがあっても) 英字のまま打つ。選ぶ前は読み
donewo<enter>	どねを
done<space><pick:2>	done
done<enter>	done
the<space><pick:16>	the
the<enter>	the
# 選んでいない語と、覚えた語に続く読みは分割しない
madeni<enter>	までに
donewo<enter>	どねを
thenoyoni<enter>	てぇのよに
# 数字を含む開発用語の確定も同じ経路 (英語として確定)。覚えた後も、手前の base6 や md は変わらない

base64<enter>	base64
